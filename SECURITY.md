# Security Policy

## Supported Versions

The following versions of Secure Password Vault are currently supported with security updates:

| Version | Supported |
| ------- | --------- |
| 3.4.x   | Yes       |
| 3.3.x   | Limited   |
| < 3.3   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit in Secure Password Vault, please do not report it through public GitHub issues or public discussions.

### Preferred Method: Private Vulnerability Reporting

Use GitHub Private Vulnerability Reporting to submit details directly and securely:

1. Navigate to the Security tab of this repository.
2. Under Advisories, select "Report a vulnerability".
3. Provide a clear description, reproduction steps, and potential impact.

### Alternative Method: Direct Contact

If you cannot use GitHub Private Vulnerability Reporting, send an email to:
- shashanksingh631@gmail.com

Please encrypt or protect sensitive details where appropriate and include:
- A description of the issue and potential security risk.
- Steps to reproduce the behavior or proof of concept.
- Affected versions and environment details.

## Response Process

- We will acknowledge receipt of your report within 48 hours.
- We will evaluate the report and confirm the severity.
- If confirmed, a fix will be developed, tested, and published as a patched release.
- A public security advisory will be published once the patch is available.
